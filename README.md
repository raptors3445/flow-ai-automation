FlowAI is a lightweight, high-performance automation SaaS tool designed to bridge traditional business workflows with Large Language Models (LLMs). It automates lead extractions, smart email summaries, and automated response drafting for service businesses.

🚀 **[Live Demo Click Here](https://your-demo-link.vercel.app)**

---

## 🔥 Key Commercial Features
- **Smart Lead Extraction:** Parses unstructured emails/messages into structured JSON data (Budget, Requirements, Names).
- **Executive Summarizer:** Converts long threads into actionable, bulleted tasks.
- **Auto Response Generator:** Generates custom proposal replies for prospective clients.
- **Production Ready Architecture:** Modular Next.js App Router setup, API route isolation, and responsive Dark UI.

## ⚡ Quick Start & Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/flow-ai-automation.git](https://github.com/your-username/flow-ai-automation.git)
   cd flow-ai-automation
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Rename `.env.example` to `.env.local` and insert your OpenAI API Key:
   ```env
   OPENAI_API_KEY=your_actual_api_key
   ```

4. **Run Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.
